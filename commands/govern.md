Use the skill-governor skill bundled with this plugin. User arguments: $ARGUMENTS

For status report the active plan and remaining scope without restarting it. For resume recover the approved plan, ledger, branch and next action using [continuation guidance](../skills/skill-governor/references/continuation.md). For audit check observed actions against loaded contracts. For install show verified sources and obtain authorization before installation. Otherwise prepare the governance plan and approval gate. Do not implement business logic.
